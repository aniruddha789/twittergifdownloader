About the tool

A free Twitter GIF downloader for public X posts

X (formerly Twitter) stores GIFs as short, silent MP4 videos. This downloader finds that MP4 on X's CDN and lets you save it at original quality, or convert it server-side into a real animated .gif for places that still require the old format.

Paste a link from x.com, twitter.com, or mobile.twitter.com. It works on iPhone, Android, and desktop with no app or browser extension. Only public posts are supported; protected, deleted, and region-restricted media cannot be downloaded.

Questions

Good to know

What links can I paste?

Paste a public x.com or twitter.com post URL that contains /status/ and the numeric post ID. Copy it from the original post; profile, search, and quote links can point at the wrong media.

Do I need to mention the bot?

No. The paste box looks up the post directly. You can still reply to a post and mention {% if bot_handle %}@{{ bot_handle }}{% else %}the bot{% endif %} if you prefer the reply flow.

What if the post has a video instead of a GIF?

Videos work too. The download page always offers the original MP4, and short videos can be converted to GIFs.

Why is the GIF larger than the MP4?

GIF is an old, inefficient format. The converter limits width and frame rate for a sensible balance between quality and file size.

Does this work with protected or deleted posts?

No. Only public posts whose media is still available from X's CDN can be downloaded.

Is it really free?

Yes. There is no sign-up or payment. Advertising and optional tips cover server and bandwidth costs.
