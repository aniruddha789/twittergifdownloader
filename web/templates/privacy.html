What this service does

{{ site_name }} turns a public X (Twitter) post or media URL into a downloadable MP4 or GIF. You do not create an account and we do not ask for your X password.

Data we process

  • The public X post link or tweet ID you paste on the homepage.
  • The media URL and tweet ID passed in the download page link.
  • Standard server logs such as IP address, browser user agent, requested path, and timestamp.
  • Temporary copies of media files while a GIF conversion is running.
  • Fingerprinted copies of converted GIFs kept in a short-lived on-disk cache.

Homepage lookups are sent to X's public syndication endpoint so we can find the media attached to a public post. We do not send pasted links to advertising partners. Temporary working files are deleted immediately after the response is sent. Converted GIFs may be cached by a hash of the source video to avoid re-encoding; the oldest entries are purged automatically and you can request removal at any time. We do not build user profiles and we do not sell personal information.

Cookies and advertising

This site includes advertising slots. When ad code is enabled, third-party advertising partners such as Google AdSense or Adsterra may set cookies or use similar technologies to measure and personalize ads. Those partners process data under their own privacy policies. If you are in a region that requires consent, a consent banner should be enabled before personalized advertising is shown.

Security

The homepage resolver only accepts public post links from x.com and twitter.com. Media downloads are restricted to approved X media hostnames over HTTPS. URLs pointing at arbitrary hosts, private addresses, or non-video files are rejected.

Children

This service is not directed at children under 13.
